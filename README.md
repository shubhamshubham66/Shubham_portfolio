## 🚀 Running Locally

This is a single static HTML file — no build step required.

```bash
git clone https://github.com/shubhamshubham66/<this-repo-name>.git
cd <this-repo-name>
```

Then just open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
